## 1. 唯一一条 CRITICAL：模板 M02 的 CSS 里有一个字面量 `PLACEHOLDER`

```css
/* templates/M02-warm-local/style.css:257 */
.ph-art { position: absolute; inset: 0; ... }
PLACEHOLDER                          ← 不是选择器，是占位符残留
  background: #F2EFE9;
  border: 1px solid #7E766E;
  padding: 5px 10px;
  ...
}
.ph-cap { position: absolute; ... }
```

**我独立复核**：

```
CSS 里 .ph-tag / .ph-cap 的定义：1 条（只有 .ph-cap，且被吞）
HTML 里 ph-tag / ph-cap 的使用：4 处
git log -S"PLACEHOLDER"：从首次提交 68f949e（2026-10-20）就存在
```

**浏览器把 `PLACEHOLDER\n background:...}` 解析成一条「类型选择器 PLACEHOLDER + 声明块」的规则，紧随其后的 `.ph-cap { ... }` 因为缺少独立选择器头被一并吞掉。**

后果：4 处图片说明（「图片位 · 16:9 · 建议 2000×1125px」+ gallery 三张）**一个像素都渲染不出来**——它们被绝对定位的 `svg.ph-art` 完全盖住。

**为什么定 CRITICAL 而不是 HIGH**：这份是**交付模板**，不是原型。它的核心用途就是「把灰阶框换成你的照片」，而说明文字是唯一的替换指引。README 让用户「搜『把这段 svg 换成』」——**那段文字本身不可见**。

Agent 做了决定性验证：把 `PLACEHOLDER` 改回合法选择器后，图注从 `top:0` 移动到 `top:554.3`，恢复 `flex` + 半透明底，证明因果唯一。

## 2. 阻断级（组 A）：S04 九块纸全部零旋转

```css
/* style.css —— 完全正确 */
transform: rotate(var(--rot));     /* 7 处 */

/* index.html —— 也完全正确 */
<figure style="--r:-1.1deg; ...">  /* 9 处 */
```

**CSS 消费 `--rot`，HTML 定义的是 `--r`。差一个字母。** 导致 7 处引用全部失效：静态旋转、入场动画关键帧、hover 位移、降级档。

## 4. 我在本轮犯的错：连续两批 agent 都在纠正我的行数

**这是本轮最该记住的自己的失误。**

| 批次 | 我给的行数 vs 实际 | 偏差 |
|---|---|---|
| 组 A（第 1 轮） | 与实际基本吻合 | — |
| **组 C-1** | S25 738→389 / S27 1119→498 / S28 1187→531 / S29 1461→381 / S25 assets/*.mjs（937 行）**不存在** | +90% ~ +283% |
| **组 C-2** | wizard.css 488→95 / mechanisms.mjs 757→114 / M02 index 1161→556 / M02 css 1243→547 | +109% ~ +564% |

**根因**：我从**宽扫产出的 `line_count`** 读数字——那是**整个切片的总行数**，被我当成单文件行数。而 `S25/assets/*.mjs` 是我凭上一轮切片的目录印象臆造的。

**两次都是 agent 自己用 `wc -l` 和 `find` 核出来并主动纠正的，不是设计保证的。** 如果它们照任务书硬凑，会漏审大量文件而报告里看不出来。

已写成 `wave2a-sweep.md` 第 9 节，含**双向义务**：主 Agent 必须现场 `wc -l` / `ls`；子 Agent 有义务核对任务书并在报告中说明范围偏差。
