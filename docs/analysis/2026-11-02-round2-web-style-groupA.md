### 🔴 阻断级：S04「拼贴墙」的九块纸全部零旋转

**这是本轮最重要的发现，也是整个项目给我最强的一课。**

| | |
|---|---|
| **位置** | `prototypes/S04-mango-collage-wall/style.css:84,93,161-163,229,234` ↔ `index.html:41` 起九个 `style` 属性 |
| **严重性** | 阻断（页面核心视觉签名完全失效） |

**证据（我独立复核过）**：

```bash
$ grep -n "var(--rot)" prototypes/S04-mango-collage-wall/style.css
84:  transform:rotate(var(--rot));
93:.slip:hover{transform:rotate(var(--rot)) translateY(-6px) rotate(.4deg)}
161:  0%{opacity:0; transform:translateY(-24px) rotate(var(--rot))}
162:  50%{opacity:.55; transform:translateY(-2px) rotate(var(--rot))}
163:  100%{opacity:1; transform:translateY(0) rotate(var(--rot))}
229:  html.js .slip.is-pasted{animation:none; opacity:1; transform:rotate(var(--rot))}
234:  .slip:hover{transform:rotate(var(--rot))}            ← 共 7 处

$ grep -c -- "--r:" prototypes/S04-mango-collage-wall/index.html
9                                                       ← HTML 定义了 9 个 --r

$ grep -c -- "--rot:" prototypes/S04-mango-collage-wall/index.html
0                                                       ← 一个 --rot 都没有
```

**根因**：CSS 消费 `var(--rot)`，HTML 定义的是 `--r`。**变量名差一个字母。**

**为什么这比 agent 描述的更严重**：agent 说"`rotate()` 收到空值导致整条 `transform` 失效"。实际影响面是 **7 处**——不只静态旋转，连**入场动画关键帧**（161-163）、**悬停位移**（93/234）、**降级档**（229）全部一起失效。九块纸不仅不旋转，连"贴上去"的入场动画和 hover 上浮都没了。

**运行时验证**：九块纸 computed transform 去重后只剩 `["none"]`，而 `getComputedStyle` 读回 `--r: '-1.1deg'`（值本身正确注入，纯粹是没人消费它）。

**这一条让我意识到框架缺一个检查**——见下文第 3 节。

## 3. 这一轮给框架的教训：变量名级的不一致需要专门的检查

**S04-1 是整轮最有价值的一条**，因为它揭示了一类**结构性缺陷**：

- 代码"看起来完全正常"——CSS 写得对，HTML 也定义了值；
- 静态通读**几乎不可能发现**，因为两个文件各自都自洽；
- 只有把"定义了哪些自定义属性"与"消费了哪些自定义属性"做**集合比对**，才能发现差集。

这类缺陷的名字是：**契约两侧的标识符拼写不一致**。同类形态还有：

| 形态 | 例子 |
|---|---|
| CSS 自定义属性名不一致 | `--rot` vs `--r`（本轮 S04-1） |
| CSS 变量零消费 | `--ri/--rj` 定义了但没人用（S04-4） |
| `id` 定义后无引用 | `price-btn`（S10-1）、`book-btn`（上轮 B1） |
| 类名定义但无对应元素 | `.flash`（S04-4） |
| 动画名/关键帧不匹配 | 待查 |

**建议加入框架**：在 `wave2-audit.md` 增加一个**机械可执行的「标识符对账」步骤**——

```
对每个切片：
  1. 提取"定义的标识符"：CSS 的 --var 定义、HTML 的 id、js 的 function/const/export
  2. 提取"消费的标识符"：CSS 的 var()、HTML 的 #id/anchor、js 的调用/import
  3. 求差集：定义了但零消费 = 死代码或拼写错误；消费了但零定义 = 必然失效
  4. 差集非空 → 每条都要判定是「死代码」还是「bug」
```

**这是纯机械的**，不需要理解代码语义，一个 `grep` + 集合运算就能做。而且它命中的往往是最难靠通读发现、影响面又最大的缺陷。

> **对零写入原则的呼应**：这类检查恰好只能靠**静态比对**，不需要跑起来。它证明了"静态审计"和"运行时验证"各有不可替代的用途——S04-1 靠静态度量发现，S08-1 靠运行时隔离验证才敢下结论。
