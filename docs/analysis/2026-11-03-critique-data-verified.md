## 二、第二致命：45% 误报率的分子分母来自两个不同实验

| | 名单 | 数量 |
|---|---|---|
| **静态命中** | S04 S05 S09 S11 S12 S13 S15 S16 S17 S18 S22 | 11 |
| **DOM 判定** | S01 S04 S08 S10 S12 S15 S16 S18 S22 S25 S28 | 11 |
| **重叠** | S04 S12 S15 S16 S18 S22 | **6** |

被判"误报"的 `S01 / S10 / S28` **根本不在静态命中名单里**——静态扫描从没"报"过它们。

而静态确实命中的 `S05 / S09 / S11 / S13 / S17` 在 DOM 裁决表里**整批消失**，既没判真也没判假。

**所以「5/11 ≈ 45%」既不是静态的误报率，也不是 DOM 的误报率——是两个实验的分子除以了另一个实验的分母。**

而这条百分比被写进了框架规则，用来支持"必须用 DOM 验证"的设计决策。

## 六、它给的三条最缺的实验

1. **对照组**——单 agent vs 两遍制，同项目同预算。**没有 ground truth，任何"能审出真东西"都是把数量当质量**
2. **精度测量**——128 条里多少是真的？**目前 0 条做过独立人工复核**。Skeptic/Arbiter 的自我裁决不算独立标注
3. **可复现产物**——`583`、`144`、`128`、`45%` 在仓库里**都只有一个数字，没有产物**。它说这条尤其讽刺："报告批评项目自带脚本只打印 JSON 不设退出码，但自己的关键测量连 JSON 都没留"

**第 3 条我完全接受。** 我用"可核验"批评别人，却把关键测量数字留在正文里。
