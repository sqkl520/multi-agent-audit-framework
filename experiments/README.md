---

## 教训

1. **实验产物必须在版本控制之内**，不能在项目目录之外
2. **一个目录消失就全归零**——应该分开存放，或者至少定期同步一份
3. **关键结论要即时写进被版本控制的东西**（框架文档），不要只留在实验目录
